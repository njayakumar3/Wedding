How to Use

  • WhatsApp (pick contact) — opens WhatsApp with the message pre-filled. You choose who to send it to.
  • Send to number — enter a phone number above (with country code like +1) to message them directly.
  • SMS — opens your default messaging app with the text ready to send.
  • Copy — copies the message so you can paste it anywhere (Telegram, iMessage, Signal, etc.).
  • Bulk sending — use send-text-invite.sh for Twilio-powered SMS to your full guest list.
